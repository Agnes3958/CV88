# CV88 — 何美佳（Agnes）交互式简历示例

此仓库包含一个为视觉设计师何美佳（Agnes）准备的交互式个人简历网页初始版本：

内容文件：
- index.html — 页面主体，包含 hero、教育、经历、科研、获奖、技能、联系等模块
- styles.css — 视觉样式（碰撞黑粉色主色调）、响应式栅格、渐入动画
- script.js — 简单交互：滚动渐入、时间线可展开、技能进度条动画

如何在本地预览：
1. 克隆仓库： git clone https://github.com/Agnes3958/CV88.git
2. 打开 index.html（建议使用 VSCode Live Server 或本地静态服务器以获得更好体验）
